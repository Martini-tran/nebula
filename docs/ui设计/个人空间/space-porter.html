导入与导出

把浏览器里的书签搬进来、搬出去。格式为 Chrome / Edge / Firefox 通用的 Netscape Bookmark HTML。 对接 POST /space/admin/bookmark-import-tasks/chrome（multipart，同步处理并返回任务）、 GET /bookmark-export-tasks/chrome?scopeType=&scopeId=（直接下载）以及两类任务的分页记录。

一、导入三步：选择文件 → 解析 → 结果

第一步先告诉用户文件从哪来（Chrome 书签管理器 → 右上角 ⋮ → 导出书签）——多数人不知道浏览器能导出。 第二步后端是同步解析，几百条通常 1–3 秒；超过 1 秒才显示进度，避免闪一下。 第三步把后端返回的 successCount / duplicateCount / failCount 摊开讲： 重复是按规范化网址判定、已跳过，不是错误；失败列出具体条目与原因。 导入保留浏览器里的文件夹结构；顶层文件夹与已有顶层目录同名即复用（再次导入「书签栏」会并进已有的「书签栏」），不会每次多出一棵树。

二、导入 / 导出记录

记录页回答「上次什么时候导的、导了多少」。状态四档对应后端 0 待处理 / 1 处理中 / 2 成功 / 3 失败； 失败行展开显示 errorMsg；待处理与处理中的任务可取消（POST /{id}/cancel）。 导出记录多一列「范围」，可一键「按同样范围再导出」。

三、导出

范围默认跟随左栏当前选择（在「前端」目录里点导出，默认就是「前端」），对应 scopeType=all|folder|tag。 实时显示将导出的条数。归档书签默认不导出、可勾选。点击后浏览器直接下载，文件名 bookmarks_yyyyMMdd_HHmmss.html， 可在 Chrome 书签管理器「导入书签」还原。
