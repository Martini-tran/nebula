书签编辑与详情

书签的一生：添加（自动识别标题与图标）→ 撞上已有收藏时提示 → 查看详情（访问记录、所在目录、备注）→ 移动或删除。 对接 POST /bookmarks、PUT /bookmarks/{id}、POST /bookmarks/move、DELETE /bookmarks/{id}。

一、添加书签

网址放第一位且唯一必填——标题、图标、描述在失焦后由后端抓取页面 <title> / og:description / favicon 自动填入， 带「已自动填充」标记，用户可改。目录默认取左栏当前目录；标签下方给出同域名书签常用的标签作为建议。 Ctrl Enter 保存。

二、重复收藏提示

后端已为每条书签存了 normalizedUrl + urlHash，前端在网址失焦时查一次： 命中就在网址下方就地提示「已收藏于某目录」，给三个选择——打开已有（跳详情，最常用）、更新已有（把本次填的标签合并过去）、仍然保存。 不拦截、不弹二次确认。需要新增按 urlHash 查询的接口。

三、书签详情抽屉

点卡片空白处（而不是标题）打开右侧抽屉，工作台不跳走。标题点击仍然是「直接在新标签页打开」—— 打开是最高频动作，不能多一步。抽屉展示卡片放不下的：完整网址、目录路径（可点跳转）、来源、近 30 天访问、备注。 E 编辑、M 移动、Esc 关闭。
