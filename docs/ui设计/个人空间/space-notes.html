临时笔记规则

  1. 新笔记默认临时 · 7 天，可在设置改成 1 / 3 / 7 / 30 天或默认长期
  2. 编辑一次，寿命重新计时
  3. 置顶、加标签、被任务或会议引用 → 自动转长期
  4. 到期归档，归档 90 天后清理
后端待补：space_note（content Markdown、color、pinned、expire_at、meeting_id、type=note|journal）； 到期归档定时任务；笔记与书签 / 任务的引用关系表。网址识别复用书签的 normalizedUrl 规则。
