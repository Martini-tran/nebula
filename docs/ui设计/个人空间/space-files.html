文件柜

个人网盘的最小版本：放证件扫描件、合同、发票、截图这类「要用时找不到」的文件。存储直接用现有 MinIO（服务已配置 nebula-system 桶）， 按用户前缀隔离。其他模块的附件（随手记里的图片、会议记录附件、稍后读存档）也统一出现在这里，一处管理空间占用。两节：文件浏览、分享链接。
