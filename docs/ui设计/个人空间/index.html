Space 个人空间 · 设计原型

ui/nebula-space 个人工作台设计：书签、随手记、任务、会议记录四个模块 + 「今天」首页，日历、专注、习惯、周回顾、搜索与设置；「更多」里的稍后读、文件柜、记账、目标与纪念日、人物卡、公开主页。二十份静态 HTML，共用同一套设计令牌 （取自 src/styles/tokens.scss 冷灰 + 靛蓝色板），支持浅色/深色。 后端为 nebula-service-space（网关 /space/**），登录复用 manager 账号。 每页末尾列出了相对现有前后端实现的差距。 书签相关页画于扩展前，除工作台外的弹窗 / 整理 / 导入页未画顶栏。

登录与访问

全站需登录。登录页（manager 统一账号 + 滑块验证码）、验证码四相位、字段级与表单级错误、 登录失效回跳原页面、已登录但无空间权限（403）、首次进入的欢迎引导。

验证码按需弹出写明回跳去处 403 不踢回登录首推导入

今天（新首页）

登录后的首页：今日任务、会议时间线、随手记输入框、今天收藏。昨天没做完的一次性处理；任意页面 Ctrl Shift Space 呼出快速记录（笔记 / 任务 / 书签 / 会议）；傍晚切成回顾卡。

要做的 + 记下的自然语言识别昨日遗留一句话日志

书签工作台

登录后的主工作区：左栏视图 / 目录树 / 标签，右侧网格或列表。粘贴网址即收藏的快捷条、 列表多选与批量操作、加载 / 空目录 / 无结果三种空状态、移动端布局与长按操作单。

一步收藏网格 / 列表 批量移动移动端

书签编辑与详情

添加书签（网址唯一必填，标题 / 图标 / 描述自动抓取）、重复收藏就地提示、 右侧详情抽屉（目录路径、来源、30 天访问、备注）、带搜索的目录选择器与删除确认。

自动填充urlHash 查重 抽屉不跳页归档优先于删除

目录与标签整理

独立的整理页：目录树拖拽（排序 vs 放入子目录两种落点）、行内改名、右键菜单、 删除非空目录的三种处置；标签颜色 / 用量 / 合并建议；失效链接集中处理。

拖拽落点删除有退路 相似标签合并301 一键更新

导入与导出

Chrome 书签 HTML 导入三步（含「怎么从浏览器导出」引导）、结果拆成新增 / 重复 / 失败并列出失败条目； 导入导出记录与失败原因；按目录或标签范围导出。

导出引导重复≠失败 同名目录复用范围跟随左栏

随手记

临时笔记默认 7 天后自动归档，置顶即转长期。便签墙、三栏编辑器（选中文字转任务）、到期前的整理列表与保留规则。

临时 / 长期到期只归档选中转任务网址变书签

任务

个人待办：收件箱 / 今天 / 计划，按清单归类。今天视图带详情面板与来源链接；未来 7 天看板带每日负荷条，会议混排；日期快捷项与重复规则预览。

优先级即描边色负荷条来源可追溯重复预览

会议记录

一个人的会议笔记本：议程带时间预算，会中 Ctrl D 标决议、@ 指派待办；我的待办自动进入任务；会后一键生成纪要并复制为 Markdown。

议程计时决议 / 待办标记上次遗留置顶纪要一键复制

日历

任务、会议、习惯、心情放到同一条时间轴。月视图每格底部是习惯完成点；日视图把未排时间的任务拖成时间块，回填专注记录对比计划与实际。

不是新数据时间块排不下提醒计划 vs 实际

专注

番茄钟挂在任务上：任务行 ▶ 发起，全屏倒计时旁放子任务清单和「记一笔」，被打断只计数；休息卡给具体建议，统计只跟自己比。

按任务记时记一笔进随手记打断计数无排行榜

习惯打卡

勾选 / 计数 / 时长三种打卡，每天或每周 N 次。本周七天打卡表、一年热力图、打卡日志与补打卡、带预设的新建流程。

断了不清零每周 N 次不催时长可由专注累计热力图

周回顾与周报

每周自动汇总：完成、决议、没做完的、七天状态。周报按模板从数据拼出草稿（不调用模型），每条带来源标签，手改部分重新生成时保留，一键复制 Markdown。

回顾给自己周报给别人来源可点回手改不丢

全局搜索与设置

Ctrl K 跨模块搜索，结果分组高亮；输入 > 进入命令模式；b: #标签 @人 is:open 等语法。设置页：模块开关、首页、节奏（晚间回顾、临时笔记天数）、通知授权。

一个框搜全部命令模式搜索语法模块可关

稍后读与摘录

书签的「读完」版：阅读队列（放太久的提示归档）、干净的阅读模式（两色划线、批注、转随手记 / 任务）、摘录库与每日回顾一条。

只进不出的解法两色划线原网址失效也能读每日回顾

文件柜

基于现有 MinIO 的个人网盘：证件、合同、发票；其他模块的附件统一管理；容量条；分享链接默认 7 天 + 提取码，可限次、可随时失效。

复用 MinIO附件一处管可撤销分享敏感文件提醒

记账

一行文字记一笔（识别金额 / 分类 / 日期），周期账单自动生成；本月支出、收入、结余与分类环图；按天数折算「应花到这里」的分类预算。

5 秒记一笔周期账单进度线预算只陈述不说教

目标与纪念日

年度目标自动从习惯、稍后读、记账、任务清单取进度，与年度时间进度对比；纪念日 / 倒数日 / 正数日，支持农历，到期前可自动建任务。

进度不用手填落后提示农历生日证件到期

人物卡

把会议、随手记、待办里对某人的提及收拢：往来时间线、互相的承诺（我欠他的 / 他欠我的）、下次 1:1 可以聊什么、太久没联系提醒。仅自己可见。

自动汇总往来承诺分两边该联系了永不外发

公开主页与分享

唯一的对外出口：可选开启的公开主页（介绍、链接、Now、书签合集、最近读完），逐块勾选公开；写明永远不会公开的内容；访客可导入合集。

默认关闭逐块公开Now 页合集可导入
贯穿全部原型的两条设计律： 一、收藏要一步，整理可以慢——粘贴网址即可保存，标题、图标、目录都有默认值，细节留给事后整理页批量处理。 二、删除之前先给退路——归档、移到未分类、撤销提示条都比确认弹窗更好用；真正不可逆的操作才需要确认，并写清会失去什么。
