书签工作台

「书签」模块的主页（登录后首页已改为「今天」）。左栏决定「看哪些」，右侧决定「怎么看、怎么动」。 对接 GET /space/admin/bookmarks/page（folderId / tagId / status / keyword）、 /bookmark-folders/tree、/space-tags。四节：网格视图、列表视图与批量操作、三种空状态、移动端。

一、网格视图（默认）

左栏三组：视图（全部 / 未分类 / 最近访问 / 已归档 / 失效，对应 status 与 folderId=0）、 目录树（带数量，悬停出现 + / 改名 / 删除）、标签（色点 chip）。 顶部常驻「粘贴网址即收藏」输入条——收藏动作必须一步完成，细节事后再补。 悬停的卡片（第二张）显示操作按钮：编辑 / 移动 / 归档 / 删除。

三、加载 / 空目录 / 无搜索结果

三种「没东西可看」要区分开：加载中用骨架屏占位，不闪白；空目录给两个出口（添加 / 从未分类移入）； 搜索无结果回显关键词，并提示「在全部书签中搜索」——用户常在某个目录里搜不到，其实书签在别处。

四、移动端

手机上侧栏收成顶部横向 chip（视图 + 最常用的目录），目录树放进「目录」chip 打开的抽屉。 列表固定为紧凑行，右下角浮动按钮添加。长按一行弹出底部操作单，替代桌面端的悬停按钮。
