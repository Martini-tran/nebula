把编排内核做成 DAG

最初只是想让"生成一篇文章"这件事可以被复用，结果一路改到了内核。

为什么状态机不够

状态机描述"现在在哪"，DAG 描述"谁依赖谁"。前者适合审批流，后者适合数据流——

而我们同时需要两者：节点内部是数据流，节点之间允许成环。

```java

// 编译期把条件组收敛成一张可续跑的图 public DagResult run(FlowGraph g, RunContext ctx) {   var order = topoSort(g, ctx.completedNodes());   return drive(order, ctx, "resume"); }
```
