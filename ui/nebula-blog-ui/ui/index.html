八套博客样式提案

都用同一批真实内容（orccode 的导航、分类、文章字段）渲染，方便直接比较气质差异而不是比较文案。 每套都是单文件、零依赖的静态 HTML，可直接在浏览器打开；确定方向后再把配色与组件结构搬进 src/styles/tokens.scss 与对应的 Vue 组件。

01

刊物 Editorial

衬线大标题、报头、栏线与编号列表。头条配首字下沉，整页靠留白和一根朱红分隔线撑起层次，几乎不用阴影和圆角。

适合：长文为主，希望读者感到"这是一本读物"而不是"这是一个产品页"。

数据字段对齐

八套页面用的都是 PostListItem 已有的字段：title / summary / coverUrl / categories / tags / publishedAt / viewCount，没有引入后端还没有的文章字段。04 的"正在写"和 08 的路线计数属于视觉示意，迁移时应接真实来源。

封面图占位

预览里的封面全部是 CSS 渐变，所以文件离线也能看。接真实数据时换成 coverUrl 即可，渐变可以保留作为无封面时的兜底。

主题切换

01 / 03 / 04 / 05 支持明暗主题；02 / 07 保持暗色阅读气质；05 / 06 / 07 / 08 含少量原生 JS 演示交互（主题、菜单、搜索、筛选），迁移时接现有 store 与 API。
