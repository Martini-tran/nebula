开源

这些站点都跑在 Nebula 上：一套 Java 21 + Spring Boot 4 的模块化后端，配 Vue 3 前端， 统一经过一个网关。启动器客户端单独开源。

  • Java 21
  • Spring Boot 4
  • Vue 3
  • TypeScript
  • MySQL
  • Redis
  • MinIO
  • Meilisearch
