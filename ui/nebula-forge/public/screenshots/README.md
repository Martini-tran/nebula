# 首页截图素材

把截图放进本目录（`public/screenshots/`），首页会自动加载。**文件不存在时显示占位块，不影响页面**。

## 主题感知（明暗自动切换）

每张图支持三种命名，按优先级回退：

1. `<名字>-dark.png` / `<名字>-light.png` —— 跟随网站明暗主题自动切换（推荐）
2. `<名字>.png` —— 不区分主题的通用图
3. （都没有）—— 显示占位块

> 「海洋」主题归为浅色，会加载 `-light` 变体。

## 需要的文件清单

| 文件名 | 用途 | 建议比例 |
|---|---|---|
| `hero.png`（或 `hero-dark.png` / `hero-light.png`） | Hero 区主界面命令面板 | 16 : 11 |
| `workflow.gif` | 工作流演示动图（唤起→搜索→启动） | 16 : 9 |
| `pinyin.png` | 拼音搜索特性 | 16 : 10 |
| `plugins.png` | 插件扩展特性 | 16 : 10 |
| `custom-plugin.png` | 自定义插件特性 | 16 : 10 |

- Hero 缺图时回退为内置的 CSS 命令面板 mockup，其余区块缺图时显示虚线占位。
- 图片建议宽度 ≥ 1200px，PNG/JPG 均可；动图用 `.gif`（若用其他格式需改组件里的 `ext`）。
- 文案与图片的对应关系定义在 `src/data/product.ts` 的 `showcaseItems`。
