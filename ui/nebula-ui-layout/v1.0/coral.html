用法边界

唯一要守住的一条：珊瑚可以做底、做图形，不要做文字色，也不要做按钮底。

✓ 这样用

珊瑚标签

对比度 5.47 / 7.38，均过 AA。

✗ 不要这样

珊瑚链接

#EC7E5B 底白字 2.73:1、作链接文字 2.73:1。
都不合格，小字场景尤其糊。

落地引用

按语义引用变量，不要直接写 hex——这样以后换色只改一处。

场景用这个变量说明
按钮 / 链接 / 选中--primary深青 #0F766E
按钮悬停--primary-hover#115E59
标签底 / 强调块底--accent-bg#FCDED5（给定 lighter）
压在标签底上的文字--accent-text#7C2D12，不可用 accent
图表主色 / 强调图形--accent#EC7E5B（给定 main）
边框 / 次级图表色--accent-border#F7B19C（给定 light）

外部原变量名 --palette-primary-lighter / light / main 也已保留，可直接对接既有设计稿。
