# Nebula Admin — Layout 设计稿

纯静态 HTML 设计稿，用于**定稿视觉规范**，定稿后再落地到 `apps/web-ele`。
不含任何构建，双击 `index.html` 直接看。

## 文件

| 文件 | 内容 |
|---|---|
| `tokens.css` | **设计令牌，唯一色彩/尺寸来源**。落地时映射到 `preferences.ts` + Tailwind |
| `layout.css` | 导航 + 表格 + 通用组件样式 |
| `index.html` | 列表页：侧栏 / 顶栏 / 页签 / 统计卡 / 搜索 / 表格 / 分页 |
| `form.html` | 表单页 + 弹窗 + **组件规范总览**（色阶、按钮、标签、输入、圆角） |
| `_preview-*.png` | 渲染截图，方便直接看效果 |

## 已定方案

- **主色**：青绿科技感 `#0D9488`（brand-500），悬停 `#0F766E`
- **侧边栏**：深墨青 `#0F1C1F`（非纯黑，与主色同色系）+ 浅色内容区
- **表格**：紧凑无框线，行高 44px，仅横向分隔线，hover 浅青底

`index.html` 右下角有**深色/浅色侧栏切换**，可当场对比后再定。

## 交互演示

- 点菜单项 → 展开/收起子菜单
- 点左下「收起菜单」→ 折叠为 60px 图标栏（hover 图标出浮层标题）

## 设计决策记录

几个不是随手定的点：

1. **success 用草绿 `#16A34A` 而非青绿**
   主色已是青绿，若 success 也用青绿，密集表格里「主色按钮」和「启用状态」会糊成一片。刻意拉开色相。

2. **语义色统一降饱和**
   后台一屏几十行，高饱和红黄会不断抢注意力。降饱和后仍可辨识，但不「跳」。

3. **折叠态分组标题退化为分隔线**
   初版用 `···` 占位，实测视觉噪音大且无信息量，改为 1px 分隔线。

4. **折叠态父项继承子项选中态**（`menu__item--has-active`）
   展开时靠子项高亮定位；一旦折叠子项不可见，父项不高亮就完全失去「我在哪」的感知。

5. **操作列按钮常驻，不做 hover 才显示**
   后台需要可发现性，hover 才出现会让不熟悉的用户找不到入口。

6. **表头 `position: sticky`**
   长列表滚动时表头不丢失。

7. **`.app__main` 加 `min-width: 0`**
   flex 子项默认 `min-width: auto`，宽表格会把整个布局撑破导致 body 横向滚动。已验证 `bodyScrollW === winW`。

## 落地映射（定稿后执行）

| 设计稿 | 落地位置 |
|---|---|
| `--brand-500` | `preferences.ts` → `theme.colorPrimary`（转 hsl） |
| `--radius` | `preferences.ts` → `theme.radius` |
| `--sidebar-*` | Vben 侧栏为语义化暗色变量，需在全局样式覆盖 |
| 表格样式 | VxeTable 主题变量覆盖（`--vxe-*`） |
| 组件样式 | Element Plus CSS 变量覆盖（`--el-*`） |

⚠️ 落地时注意：改 `preferences.ts` 必须同步 `VITE_APP_NAMESPACE` 版本号 +1，
否则老用户 localStorage 旧配置会压过新值（defu 前者优先）。详见
`apps/web-ele/CLAUDE.md` 第 11 节。
