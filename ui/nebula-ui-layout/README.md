# Nebula Admin — Layout 设计稿

纯静态 HTML 设计稿，用于**定稿视觉规范与导航结构**，定稿后再落地到 `apps/web-ele`。
无需构建，双击对应目录下的 `index.html` 即可查看。

## 两个版本

| 版本 | 导航结构 | 入口 |
|---|---|---|
| [v1.0](v1.0/) | **深色侧栏平铺全部菜单**（经典后台） | `v1.0/index.html` |
| [v2.0](v2.0/) | **顶部大类 + 侧边子菜单**（混合导航） | `v2.0/index.html` |

两版**共用同一套设计令牌**（`tokens.css` 完全相同）——主色、圆角、
表格样式、组件规范都一致，**差异只在导航结构**，可直接对比取舍。

```
v1.0                              v2.0
┌────────┬──────────────┐         ┌──────────────────────────┐
│ 深色   │  顶栏        │         │ 深色顶栏：一级大类导航    │
│ 侧栏   ├──────────────┤         ├────────┬─────────────────┤
│ 全部   │   内容区     │         │ 浅侧栏 │    内容区       │
│ 菜单   │              │         │ 当前类 │                 │
│ 平铺   │              │         │ 子菜单 │                 │
└────────┴──────────────┘         └────────┴─────────────────┘
```

## 已定的视觉方案（两版通用）

- **主色**：青绿科技感 `#0D9488`（brand-500），悬停 `#0F766E`
- **表格**：紧凑无框线，行高 44px，仅横向分隔线，hover 浅青底
- **圆角**：`--radius: 0.5rem`（8px 基准）
- **success 用草绿 `#16A34A` 而非青绿**：主色已是青绿，若 success 同色系，
  密集表格里「主色按钮」和「启用标签」会糊成一片，刻意拉开色相

## 建议

**v2.0 更适合本项目**：现有 13 个路由模块约 45 个页面，其中「AI 能力」
一类就有 11 个子页面。v1 全平铺需要大量滚动和多层手风琴；v2 的
「顶部切域 + 侧边切页」正好匹配「域切换少、域内切换多」的实际使用模式。

详细对比见 [v2.0/README.md](v2.0/README.md)。

## 落地注意（两版通用）

改 `preferences.ts` 后必须同步把 `.env` 的 `VITE_APP_NAMESPACE` 版本号 +1，
否则老用户 localStorage 旧配置会压过新值（defu 前者优先）。
详见 `apps/web-ele/CLAUDE.md` 第 11 节。
