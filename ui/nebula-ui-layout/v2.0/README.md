# Nebula Admin v2.0 — 无卡片通栏 + 混合导航

**独立设计，不继承 v1.0。** `tokens.css` / `layout.css` 都是 v2 自己的一套，
与 v1.0 同名文件内容完全不同，改 v2 不会影响 v1。

双击 `index.html` 查看，无需构建。

## 文件

| 文件 | 说明 |
|---|---|
| `tokens.css` | **v2 独立令牌**：冷灰中性色 / 4px 圆角 / 13px 字号 / 紧凑尺寸 |
| `layout.css` | **v2 独立实现**：顶栏两行导航 + 通栏内容 + 紧凑表格 |
| `index.html` | 列表页 |
| `form.html` | 表单 + 弹窗 + 组件规范总览 |

## 与 v1.0 的差异

导航结构和视觉风格**两条线都不同**：

| | v1.0 | v2.0 |
|---|---|---|
| 导航 | 深色侧栏平铺全部菜单 | **顶栏大类（图标上/文字下）+ 侧栏子菜单** |
| 内容容器 | 灰底 + 白卡片（边框+圆角） | **白底通栏，无卡片**，靠分割线分区 |
| 圆角 | 8px | **4px** |
| 基准字号 | 14px | **13px** |
| 表格行高 | 44px | **38px** |
| 控件高度 | 32px | **28px** |
| 页签 | chrome 胶囊式 | **下划线式** |
| 状态标签 | 色块底 | **圆点 + 文字**（色块底仅强调时用） |
| 统计卡 | 独立卡片网格 | **通栏等分统计条**，竖线分隔 |
| 搜索表单 | 标签在上 | **标签内联在左**（省高度） |
| 中性色 | 暖灰 | **冷灰** |
| 主色 | brand-500 `#0D9488` | **brand-600 `#0F766E`**（下沉一档） |

## 关键设计决策

1. **内容区直接白底通栏，不用卡片**
   v1 是「灰底 + 白卡片」，卡片边框在一屏多区块时会产生大量重复描边。
   v2 内容区就是白底，区块之间只用 1px 分割线，视觉噪音显著降低。

2. **表格贴边对齐**
   首末列 padding 等于 `--content-pad-x`(20px)，与上方 searchbar / toolbar
   的内边距对齐，形成一条干净的垂直基准线。已验证首列 `padding-left: 20px`。

3. **顶栏选中态用「亮字 + 底部指示条」，不用实心色块**
   两行导航项本身面积就大，再填实心主色会过重；指示条更利落，也更像导航。

4. **状态默认用圆点而非色块底**
   紧凑表格里一列色块底会让整页显脏。需要强调的场景保留 `.tag--block`。

5. **主色下沉到 brand-600**
   通栏风格下主色出现面积更大（按钮、选中态、链接），500 太亮，600 更稳。

6. **表单标签在左**
   通栏 + 紧凑的前提下，标签在上会让表单高度接近翻倍。

## 顶栏规格

| 项 | 值 | 变量 |
|---|---|---|
| 顶栏总高 | 68px | `--topnav-height` |
| 导航项 | 52px 高 / 最小宽 76px | `--topnav-item-width` |
| 图标 | 20px，描边 1.6 | `.topnav__icon` |

徽标绝对定位在图标右上角，带 1.5px 描边（跟随底色）。
窄屏（≤1280px）只收窄间距、隐藏 logo 文字，**不隐藏导航文字**——
两行结构里文字是主要辨识依据。实测 1200px 视口无横向溢出。

## 顶部大类划分

| 顶部大类 | 侧栏子菜单 |
|---|---|
| 工作台 | 分析页、工作台 |
| 博客 | **内容**：文章/随笔/标签/分类/系列　**任务**：导入任务 |
| AI 能力 | **智能体**：定义/实例/回放/迭代链　**编排**：流程列表/AI对话　**模型资产**：知识库/MCP/模型档案/提示词/AI工具 |
| AI中转 | 服务商/套餐/套餐类型/AI模型/支付方式/推荐测评/充值记录 |
| 个人空间 | 书签/目录/标签/导入/导出任务 |
| 系统 | 用户/文件/菜单管理 |

> 顺带解决了一个现存问题：`ai-knowledge`/`ai-mcp-server`/`ai-model-profile`/
> `ai-prompt`/`ai-tool` 五个模块在现有路由里 order 都是 305、title 都叫
> 「AI模型」，实际是被拆散的同一组，v2 收进「AI 能力 → 模型资产」。

## 交互

- 点顶部大类 → 侧栏换成该类子菜单，自动选中第一个子项，面包屑/页签同步
- 点侧栏子项 → 切换页面
- 侧栏可折叠为 56px 图标栏，hover 出浮层标题

菜单数据在 `index.html` 底部的 `MENU` 常量，结构与后端 `/system/menu/all`
一致（一级 = 大类，`children` = 子菜单，`group` 做二级分组）。

## 落地注意

v2 的路由 `meta` 不需要改数据结构——现有路由已是两层（父分组 + children），
布局组件改为「读第一层渲染顶栏、读 children 渲染侧栏」即可。

改 `preferences.ts` 后记得把 `.env` 的 `VITE_APP_NAMESPACE` 版本号 +1，
否则旧 localStorage 会压过新配置。详见 `apps/web-ele/CLAUDE.md` 第 11 节。
